# 知行 · 架构地图

独立的 Three.js + Vite 架构浏览器。无需启动业务前后端、Redis 或模型服务。

```bash
cd architecture-viewer
npm install
npm run dev
```

打开 http://127.0.0.1:5180 。开发服务器仅监听本机。

文件建筑群位于 http://127.0.0.1:5180/city.html ，与原架构地图独立切换。前后端分别成园区，每个被索引文件对应一座按职责造型的建筑；目录边界严格包含子目录和文件。支持目录树、路径导航、聚焦建筑、静态导入 / 反向导入、人工整理的跨端业务关系和凭证跨城演示。手机及 WebGL 不可用时可使用目录平面。

`src/city/model.js` 维护十类建筑符号、核心文件职责和业务链路。其他职责按路径推断并在详情标注；函数和类只识别部分静态声明。业务演示中的连接表达过程交接，可能经过未展开的中间文件，不等同于直接调用。

## 第一版功能

- 16 个核心模块的三维分层总览，支持旋转、缩放和视角复位。
- 二维层级视图；WebGL 不可用时自动使用二维。
- 模块、文件路径和接口搜索，技术层级筛选，直接关联高亮。
- 7 步凭证分析链路，支持逐步选择、播放、暂停和重播。该动画是流程演示，不是实时调用追踪。
- 模块职责、上游与下游、Flask 接口及源码详情。源码查看器支持行号定位、项目内静态导入和反向导入导航。
- 导出不含源码正文的 JSON 地图数据。

## 数据如何更新

两张地图顶部均有“重新索引”按钮和索引时间。点击后，本地服务重新读取文件、目录、源码、接口和静态依赖，再刷新地图（返回初始视角）；失败会保留当前地图并提供重试。`npm run dev` 还会在源码增删改时自动刷新。`npm run preview` 支持按钮手动刷新索引，但不监听源码变化。

开发和预览页面通过本地 `/__architecture/index` 接口读取当前源码，POST 用于手动重建。单独托管 `dist/` 且没有该接口时，只能展示构建快照；按钮会说明需要启动本地服务。重新索引不自动改写人工整理的职责说明和业务关系。

`scripts/scan.mjs` 在启动 / 构建时读取项目源码。开发模式监听源码增删改并刷新快照。扫描范围为 `frontend/src`、`backend` 的 JS / JSX / Python / SQL / CSS / JSON（含测试和翻译资源），以及白名单中的部署、前端构建配置、语言检查脚本和依赖清单；跳过隐藏目录、符号链接、上传材料和依赖目录，不读取 `.env`、数据库或用户文件。两座文件园区展示前后端内的被索引文件；根目录 Compose 配置仍在原架构总览中展示。

`src/model.js` 人工维护业务模块、关系、布局和凭证流程。它们与自动扫描的接口、行数和文件导入分开标注。导入分析是轻量静态模式匹配，不覆盖所有语法、动态导入、Python 相对导入或运行时调用；不声称是完整调用图。源码变更引起的业务结构变化需要相应更新该模型。

静态构建会包含扫描到的项目源码快照，适合本地使用或在允许阅读源码的环境内分享。JSON 导出不含源码正文。

```bash
npm run check
npm run build
npm run preview
```

`check` 验证模块文件、关系端点、流程源码锚点和代表性的扫描结果。`dist/` 是可独立预览的构建产物；没有本地索引接口时，后续源代码变更需重新构建。
